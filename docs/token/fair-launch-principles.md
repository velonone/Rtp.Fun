# Verifiable Fair-Launch Principles

Rtp.Fun intends any native-token launch to be verifiable from public facts rather than supported only by marketing language.

A launch manifest should publish, where applicable:

- token identifier and network;
- public launch transaction;
- total supply;
- private-sale and presale status;
- team / insider launch allocation;
- launch-price advantage policy;
- mint / freeze / administrative authority state;
- treasury policy;
- contract and manifest digests;
- distribution snapshot and verification timestamp.

## Economic-rights boundary

This framework does not itself create a dividend, revenue-share, profit-share or other economic right.

Any such right requires separate legal, governance and implementation review before public representation.

## Public wording

Preferred: **Verifiable Fair Launch**.

Avoid: “100% fair” as an unsupported slogan if the corresponding launch evidence has not yet been published.
