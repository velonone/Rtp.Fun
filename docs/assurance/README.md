# Assurance Center

This directory defines how Rtp.Fun describes public security and release evidence.

## Evidence classes

| Class | Issuer | Meaning |
| --- | --- | --- |
| **Designed Against** | Rtp.Fun | A control is intentionally designed around a published objective or standard. |
| **Conformance Evidence** | Rtp.Fun | Reviewable tests or release evidence support the stated contract. |
| **Production Observed** | Rtp.Fun | The named behavior was observed on the named production path. |
| **Independently Assessed** | Named third party | An external assessor evaluated the stated scope. |

A higher-sounding badge may not replace a lower evidence class. Self-issued conformance material is not presented as an independent audit.

See [Standards Crosswalk](standards-crosswalk.md) and [Certificate Policy](certificate-policy.md).
