# Certificate and Assessment Policy

Rtp.Fun distinguishes four classes of public assurance material.

1. **Self-issued conformance record** — generated or reviewed by Rtp.Fun and clearly named as such.
2. **Production observation record** — a scoped statement tied to a release or execution path.
3. **Independent assessment** — issued by a named third party with a published scope.
4. **Formal certification** — used only when an identified certification process and issuer apply.

A badge must never visually imply a higher class than the underlying evidence.

## Current public posture

No independent security assessment or formal certification is represented by this repository unless a named external artifact is added here with its exact scope.
