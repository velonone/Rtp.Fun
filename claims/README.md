# Public Claims Registry

Material trust claims in this repository are mirrored as machine-readable records.

Rules:

- claim identifiers are stable;
- evidence is scoped;
- a claim can stop at any assurance level;
- a claim does not inherit evidence from another chain, venue or capability;
- retired claims remain distinguishable from current claims;
- an independent assessment requires a named external issuer and publishable reference.

The public registry is intentionally much smaller than the private implementation surface.
