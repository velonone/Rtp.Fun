# Public Claims Registry

Material trust claims in this repository are mirrored as machine-readable records.

Rules:

- claim identifiers are stable;
- evidence is scoped;
- a claim can stop at any assurance level;
- a claim does not inherit evidence from another chain, venue or capability;
- retired claims remain distinguishable from current claims;
- an independent assessment requires a named external issuer and publishable reference.

The public registry is intentionally much smaller than the private implementation surface.

## Evidence available here

The [24 October 2026 product record](../evidence/releases/2026-10-24/README.md) provides a dated, first-party summary for the product-page observations. Its screenshots establish interface content, not completion of every action within those pages.

The AMS and execution records describe **architecture and control objectives**. Release-specific public conformance artifacts for those records have not been published here. Their conservative evidence level does not assert that implementation is absent; it prevents an architecture document from being presented as a published test result or independent assessment.
