# Contributing

This is a curated public trust repository, not the Rtp.Fun production source tree.

## Useful contributions

- documentation corrections;
- broken public links;
- standards-mapping corrections;
- reproducible inconsistencies between a public claim and its published evidence;
- schema and evidence-format improvements.

## Do not submit

- credentials or secrets;
- production host or topology information;
- private provider details;
- exploit instructions or suspected vulnerabilities in a public issue;
- copies of private product source code.

Security issues should follow the official Responsible Disclosure process at https://rtp.fun/docs/disclosure/.
