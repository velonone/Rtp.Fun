# Brand assets

This repository uses the official RTP geometry from the product source.

| Asset | Use |
| --- | --- |
| `rtp-mark-brand.svg` | Primary repository mark |
| `rtp-logo-brand.svg` | RTP wordmark |

## Rules

- Do not redraw, reinterpret or replace the RTP geometry.
- Keep the mark small and deliberate.
- Product screenshots should come from the official product or official Docs.
- Do not publish generated security seals, fake certificates or visual badges that imply a third-party audit.

A GitHub social preview is intentionally not shipped until a brand-approved final composition exists.
